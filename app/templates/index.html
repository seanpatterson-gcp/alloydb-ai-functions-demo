Cohere-10M Dataset Schema & Semantics

The benchmark dataset consists of 10 million vector embeddings generated from Wikipedia articles using Cohere's 768-dimensional multilingual embedding models.

Column Type Description
id BIGINT PRIMARY KEY Unique identifier for the passage chunk.
title TEXT Wikipedia article title.
text TEXT Paragraph passage text (100–300 words).
url TEXT Canonical Wikipedia URL.
views INTEGER Page view count for popularity weighting and hybrid filtering.
langs TEXT Language identifier (e.g. 'en').
embedding vector(768) 768-dimensional float32 vector embedding indexed via ScaNN.

Google ScaNN Index Definition & Tuning

CREATE INDEX cohere_scann_idx 
ON cohere_wikipedia 
USING scann (embedding vector_cosine_ops)
WITH (
    num_leaves = 1000,
    quantizer = 'sq8'
);
  • Scalar Quantization (sq8): Compresses 32-bit floats into 8-bit integers, yielding a 4x reduction in memory overhead while maintaining >98% recall accuracy.
  • Centroids (num_leaves = 1000): Partitions the vector space into 1,000 Voronoi cells, pruning irrelevant regions during query execution.
  • Runtime Knobs: SET scann.num_leaves_to_search = 50; controls search precision vs throughput dynamically.
